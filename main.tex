\title{Development of ePATH Test Bench and Supporting Tools}
\author{Andreani Kalatha}
\maketitle

\begin{abstract}
This report provides a summary of the projects completed over the course of my internship. My primary assignment focused on the development of the ePATH Test Bench, an automated testing software that verifies the functionality of the ePATH board. After overcoming challenges arising with the multimeter communication, I designed three PCB boards compatible with the Arduino DUE, with the third design demonstrating reliable performance. I also developed a graphical user interface to facilitate test execution and designed a custom casing to house the PCB. In addition to the main project, I worked on several smaller initiatives. These included creating an interface to save serial monitor data to a text file, researching electrical switching methods to alternate between ePATH displays, and developing an assessment method to evaluate the accuracy of catheter alignment.
\end{abstract}
