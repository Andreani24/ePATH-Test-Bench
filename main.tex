\title{ePATH Test Bench}
\author{Andreani Kalatha}
\maketitle

\begin{abstract}
This document provides an overview of the projects I completed during my internship. My primary assignment focused on the development of the ePATH Test Bench, which was designed to verify the functionality of the ePATH board. As part of this project, I designed three PCB boards compatible with the Arduino DUE, with the third design demonstrating satisfactory performance. I also developed a graphical user interface that provided a user-friendly approach for conducting all required tests. In addition to the main project, I worked on several smaller initiatives. These included creating an interface to save serial monitor data to a text file, researching electrical switching methods to alternate between ePATH displays, and developing an assessment method to evaluate the accuracy of catheter alignment.
\end{abstract}
