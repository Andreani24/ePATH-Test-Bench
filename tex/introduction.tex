\section{Introduction}
During the internship at Pathfinder medical, I completed a number of projects. The main project I worked on is the ePATH Test Bench, which this document mostly focuses on. The purpose of this project was to perform automated testing on the ePATH board to ensure it operates properly. In addition to this, I undertook several smaller projects. I developed a graphical user interface (GUI) to efficiently save Arduino serial monitor data to text files. I also researched electrical switching methods to alternate between ePATH displays, aiming to replace the currently insufficient mechanical switching approach. Finally, in a collaborative project, I contributed to the development of a method for evaluating the accuracy of catheter alignment displayed on the ePATH screen. These projects are thoroughly described in the following document.

All project-related files are stored in the Resources folder within the company’s Google Drive, under the Andreani directory.
