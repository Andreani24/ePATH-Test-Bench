
\section{Conclusion}
The development of the ePATH Test Bench represented a comprehensive effort to design, prototype, and refine both hardware and software solutions that support reliable testing of the ePATH board. Starting from initial communication challenges with measurement equipment, progressing through three PCB iterations, and leading to the implementation of a graphical user interface, the project addressed multiple technical domains. Each PCB version provided valuable insights related to component selection, footprint accuracy, or power and switching requirements that contributed to more robust subsequent designs. Overall, this work established a solid platform for continued development, ensuring that both the ePATH Test Bench and the supporting tools can deliver greater accuracy, reliability, and ease of use in future iterations.

In parallel, several smaller projects were carried out that complemented the main work. The investigation into electrical display switching provided viable design propositions for improving alignment assessment across multiple ePATH displays, highlighting relays and shift registers as the most effective solution. The development of a GUI for saving text files simplified data acquisition from the Arduino environment, while the alignment accuracy assessment project explored methods for evaluating catheter positioning accuracy.
