\section{Electrical display switching}
To evaluate the alignment consistency across different ePATH devices during assembly and prior to release for use, a setup was proposed where a single crossing and target catheter kit is connected to multiple (currently three) ePATH displays. To streamline switching between displays, without manually disconnecting the catheter kit, which would require its removal from the saline tank, a switching mechanism is necessary. Although mechanical switching methods have been considered, an electronic switching solution is preferred for improved reliability and ease of use. Several electronic components that would enable the switching were explored as detailed below.

\subsection{Background}
Firstly, the idea of using solid state relays (SSRs) was explored \cite{ssr_rfwireless}. A large advantage of using this is that SSRs are optically isolated. Therefore, the input and output are physically isolated which enhances precision by minimizing noise. This will be very useful in this system to prevent any noise influencing the alignment displayed between the connected devices. Other advantages include their ability to work with both DC and AC signals, their silent operation and low power consumption. A potential problem when working with SSRs is that they are all susceptible to electrostatic discharge to some degree because they are built from semiconductor devices. 

Secondly, transistors were considered as an alternative switching method \cite{transistor_switch}. They offer a wide range of advantages such as their reliability and quick switching. Transistors can be arranged in Darlington or Sziklai configurations which increases the input impedance further. There is a wide variety of transistors for different operating conditions thus choosing the appropriate transistor involves more calculations. A big disadvantage is that the inputs and outputs are not isolated so even if the transistor is off there might be some leakage current that interferes with the displayed alignment.

Multiplexers (MUX) can also function as electronic switches. For instance, the SN74CBT16214CDLR \cite{sn74cbt_datasheet} offers twelve independent 3:1 MUX channels, which can be utilized for signal routing. Like relays, MUX channels exhibit high impedance when not selected, but they tend to be more susceptible to electrical interference. It's also important to note that no more than one port can be used at a time in MUX, which restricts potential future expansions of the project. Moreover, MUX devices cannot handle AC signals unless they feature dual-supply operation. Without this, switching an AC signal would require offsetting the signal within the range of VCC and ground, which can introduce additional design challenges.

Tri-state buffers were also considered to be used as switches. They enable or disable the connection between input and output via changes in impedance \cite{digital_buffer}. However, they were quickly ruled out upon determining that their output is limited to only three states: logic high (1), logic low (0), or high impedance (Z). As a result, they cannot transmit analogue signals, which are the type of signals involved in our application. Another component that was quickly rejected was the silicon-controlled rectifier (SCR) \cite{scr_switch}. The main drawback is the difficulty of turning off a conducting SCR, which requires specialized commutation circuits to force the switch open. Additionally, SCRs can unintentionally turn on due to a high rate of voltage change (dv/dt) at the source which might occur due to electrical interference. It should be noted however that one advantage of the SCR, compared to a transistor, is that it operates strictly in binary states: either fully on or fully off, with no active region of operation.

For the reasons outlined above, particularly the significant advantage of opto-isolation, relays were selected to implement the electrical switches. These relays will be controlled by shift registers, which are themselves managed by an Arduino. Shift registers were chosen as they are relatively easy to control and have flexible functionality allowing many pins to be on simultaneously.

\subsection{Design proposition}
The crossing catheter has 4 connecting wires and the target catheter 2. Therefore, there are 6 connections per display that need to be switched on or off. Since there are 3 displays, this is an overall of 18 connections that need to be controlled. Therefore, 18 Single Pole Single Throw (SPST) relays would need to be used, or 9 dual SPST relays like ASSR-1420-302E \cite{assr_datasheet} or 5 quadrable SPST like AQS221N2SX \cite{panasonic_series1960_catalog_2025}. These can be controlled by 8-bit shift registers like SN74AHCT595PWR \cite{shift_register}. The block diagram in Figure \ref{button_wiring} shows the connection between a particular pin on a catheter and its corresponding connecting point with the displays when using SPST relays. This circuit configuration would need to be replicated for the remaining five display pins. This is the first possible design configuration.

This system could be complex to control because of the large number of SPST relays. For the second design structure, to minimize the number of relays required, an alternative approach is to connect the inputs of all three displays to one common bus for the crossing catheter and another bus for the target catheter. The catheter kit is also connected to these buses, allowing communication with any of the displays. By selectively powering on only the desired display, we ensure that only one display is actively sending and receiving signals at a time. 
To turn on and off the appropriate display, relays can be used. Each display is powered by 2 wires; the ground and the voltage wire. The ground connection of all the displays can be connected. The voltage wire of each display can be switched on and off using 3 SPST relays controlled by a shift register.  The block diagram of such a connection is shown in Figure \ref{button_wiring1}. An important thing to consider when choosing these relays is that they must be rated to handle the voltage and current required to run the ePATH display.

One drawback of this wiring method is that an ePATH display must be powered on each time a switch is made, requiring the startup process to complete before use. As a result, this approach is slower and less efficient compared to Design 1.


In conclusion, to electrically switch the catheter connections between the three ePATH displays, a combination of relays and shift registers was determined to be the most effective solution. Among the configurations considered, Design 1 was found to be the most suitable for implementing the system with minimal interference.





\section{Text file saving}
Data printed in the Serial monitor of Arduino IDE can easily be lost and is difficult to work with. To make data acquisition and handling easier, a simple GUI was developed that captures the printed data and saves it in a .txt file. The GUI consists of a:
\begin{itemize}
\item A list-box that displays the information printed on the Serial monitor. 
\item A save button that saves the data in a text file at the desired directory.
\item A clear button that deletes data in case they were corrupted.
\item An information button that displays an information window that explains the GUI's functionalities.
\end{itemize}

The python code used to develop this GUI is in the resources folder under the name Save text files.
